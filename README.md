# Mitti Dhaba

**Name:** Amna Hameed
**Roll No:** i263058
**Section:** B

**Theme:** Café / Dhaba Menu
A website for Mitti Dhaba, a desi roadside dhaba in Islamabad, showing its menu, food gallery and contact details.

## Pages
- **Home** (`index.html`): welcome section, today's specials and an Order button
- **Menu** (`menu.html`): full menu in five categories (Chai, Breakfast, Main Course, Breads, Drinks) with Order buttons
- **Gallery** (`gallery.html`): six dishes in a 3-column grid with "Like this dish" buttons
- **Contact** (`contact.html`): address, phone, opening hours and a contact form
